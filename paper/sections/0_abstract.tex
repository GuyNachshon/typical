Software that calls a language model to make a bounded decision -- route this ticket, flag this
transaction, score this alert -- usually recovers the decision from generated answer symbols,
constrained decoding, or candidate log-probabilities, even though what the caller needs is a
distribution over a label set defined at request time. We ask whether a pretrained causal language
model can expose that decision \emph{directly}, without generating an answer, and what must remain
inside its computation for the decision to stay question-conditioned. Our central result is negative
and scoped. A decision state computed \emph{before} the candidate set is known -- the formulation
that would make one state reusable across arbitrary candidate sets -- transfers a listwise teacher's
candidate priors and calibration but not its question-conditioned closed-book capability. This holds
across six tested factorizations and distillation objectives and at both backbone depths we tapped,
and it is invisible to raw accuracy: it appears only under $\dq$, the drop in accuracy when the real
question is replaced by a shuffled one with the candidate set held fixed. \textbf{Typical} instead
renders the query and its runtime-defined candidates inside one causal suffix against a state whose
key-value cache is computed once, and scores the terminal decision state against each candidate's own
\emph{contextual} hidden state. That readout recovers the question-conditioned signal of a
letter-generating interface ($\dqsh$ .106 vs.\ .109; teacher .102) with about a quarter of its order
sensitivity, and carries typed output contracts -- categorical Choice, ordinal Score, Bernoulli Noul
-- plus an abstention gate factored out of the candidate softmax. Standard bounded decisions
generally improve with backbone scale (1.7B--14B, with an anomalous 8B point) and soft-target
probability quality improves substantially at fixed capacity through objective and
checkpoint-selection changes. The boundary is sharp and we report it as prominently: hard
compositional decisions remain unresolved at every size we trained, and a same-size \emph{frozen}
backbone read with three in-context exemplars is not beaten there by any model we fine-tuned.
